# Common Function Gallery

An interactive Math 172 reference for browsing common function graphs, practicing function identification, and exploring transformations.

## Publish through GitHub and Netlify

1. Extract the ZIP.
2. Upload **the contents of the extracted folder** to the root of your GitHub repository. Keep the `assets` folder intact.
3. In Netlify, import the GitHub repository.
4. Leave the build command blank.
5. Set the publish directory to the repository root: `.`
6. Deploy the site.

The repository root should contain:

- `index.html`
- `styles.css`
- `script.js`
- `assets/`

Do not upload the outer `common-function-gallery` folder as an extra nested level unless you set that folder as Netlify's base or publish directory.
